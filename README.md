# EDU_PROJECT_3 Проект по БД
В рамках проекта закреплены навыки по реализации получения данных о компаниях и вакансиях с сайта hh.ru, спроектировать таблицы в БД PostgreSQL и загрузить полученные данные в созданные таблицы.  

## Структура проекта
### Модуль external_api_hh.py
Содержит класс для подключения к внешнему API HH.ru и методы получения списка компаний и вакансий
### Модуль utils.py
Содержит функции создания БД, ее табличной структуры и записи полученной информации от API в БД
### Модуль db_manager.py
Содержит класс для работы с БД и методы получения информации из БД по SQL-запросам
### Модуль exceptions.py
Содержит пользовательское исключение
### Модуль config.py
Преобразует скрытую информацию из файла `database.ini` в словарь, для дальнейшего использования в проекте
### Модуль user_settings.py
Содержит список ID-компаний учавствущих в работе программы
### Модуль main.py
Содержит главную функцию запуска программы и точку входа

## Файлы настройки
`database.ini` содержит пользовательские данные для подключения к БД.  
При использовании проекта переименуйте файл `database.ini_template` и внесите свои данные  
`env` содержит имя БД для первичного подкючения.  
При использовании проекта переименуйте файл `.enc_template` и внесите свои данные
